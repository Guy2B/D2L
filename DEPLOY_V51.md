# Déploiement V51

Le ZIP V51 est structuré pour être extrait directement à la racine du dépôt `D2L`.

Les photographies des carnets sont dans :

`assets/articles/voyages/`

Les pages individuelles sont dans :

`textes/<slug>/index.html`

Pour déployer : extraire le contenu du ZIP dans le dossier `D2L` en remplaçant les fichiers existants, puis publier le dépôt comme habituellement.
