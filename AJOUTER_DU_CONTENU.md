# Ajouter un nouveau contenu

1. Ouvrir `studio.html` dans Chrome.
2. Choisir **Nouveau texte** ou **Nouveau roman**.
3. Remplir le formulaire. Pour un poème, conserver simplement les retours à la ligne.
4. Ajouter une image et son crédit si souhaité. L’atelier compresse l’image en WebP.
5. Ouvrir l’onglet **Contenu ajouté** et cliquer sur **Exporter custom-content.js**.
6. Remplacer le fichier `custom-content.js` du site par celui qui vient d’être téléchargé.
7. Recharger `index.html`. Le contenu apparaît automatiquement dans la bibliothèque, la recherche, la chronologie et les compteurs.

Pour publier sur internet, envoyer ensuite le dossier du site mis à jour sur votre hébergeur.

## Important

Les brouillons de l’Atelier sont conservés dans le navigateur avec `localStorage`. Le fichier exporté reste la source à publier pour que tous les visiteurs voient les nouveaux contenus.
