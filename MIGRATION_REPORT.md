## Principes appliqués

1. Le livret sert de source de contenu, pas de rubrique mise en avant.
2. Chaque texte est une publication autonome.
3. Les dates d’origine sont conservées lorsqu’elles sont documentées.
4. Le lien vers la publication originale reste disponible.
5. Les republications externes sont signalées par `Aussi publié sur...`.
6. Les crédits des images sont conservés quand ils ont été fournis.
7. Aucun tiret long n’est utilisé dans les textes affichés.
8. Les images fournies par l’auteur ont priorité sur les anciennes miniatures compressées.
